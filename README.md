# Supplier Quality Analysis Dashboard

## Overview
This project focuses on analysing supplier quality and its impact on manufacturing operations.

A manufacturing company faced challenges in tracking supplier performance due to the absence of a centralized procurement and quality monitoring system. Data was collected across multiple plants, including information on materials, vendors, defects, and downtime caused by defective materials.

The goal of this dashboard is to identify underperforming vendors, highlight production risks, and support data-driven decisions to improve overall operational efficiency.

## Business Problem
The company needed visibility into:
- Which suppliers are providing low-quality materials  
- How defects are impacting production downtime  
- Inconsistencies across plants and vendors  
- Poor-performing combinations of materials, vendors, and locations  

## Key Questions Answered
- Which vendors and plants generate the highest defect quantities?  
- Which vendors and plants cause the most downtime?  
- Are there specific vendor-material combinations with poor performance?  
- How does the same vendor perform across different plants?  
- Which plant-vendor relationships are most problematic?  

## Dashboard Structure
- **KPI Section:** Total defects, total downtime, key performance indicators  
- **Trend Analysis:** Defects and downtime over time  
- **Breakdown Analysis:** Vendor, plant, material, and defect type comparisons  
- **Insights Section:** Key areas requiring attention  

## Skills Demonstrated
- Data modelling in Power BI  
- Data cleaning and transformation using Power Query  
- DAX measures for defect and downtime analysis  
- Building KPI-driven dashboards  
- Creating interactive reports using slicers and filters  
- Analytical thinking and business problem solving  

## How to Use This Repo
1. Download the `.pbix` file from the `power-bi-files/` folder  
2. Open it in Power BI Desktop  
3. Use slicers to explore vendor, plant, and material performance  
4. Analyse trends and identify key problem areas  

## What to Notice
- Vendors contributing most to defects and downtime are clearly highlighted  
- Cross-filtering allows comparison across plants and materials  
- The dashboard is structured to move from summary → analysis → insight
